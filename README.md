A single-line weather forecast for Puddlewick, a city that does not
exist, written for a bored commuter at a rainy bus stop.

`main.py` (Python 3, standard library only, no network) writes the
same line to `/output/entry.txt` on every run. The line keeps the
shape of broadcast weather — place, timing, high and low — and bends
it with a sun that apologises for yesterday and a numbered bus that
runs fashionably late.

Run it with:

```sh
python3 main.py
```
